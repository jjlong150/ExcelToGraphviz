# Security

## Reporting a Vulnerability

If you discover a security issue in Excel to Graphviz - including in the SVG postprocessing feature - please report it privately by emailing relationship.visualizer@gmail.com rather than opening a public issue. I actively monitor this address and will acknowledge reports within 5 business days, aiming to have a fix or mitigation in place before any public disclosure.

When reporting, please include:

- Steps to reproduce the issue
- The affected version of Excel to Graphviz
- If applicable, the workbook, `.dot` file, or generated SVG that triggers it

## Full Security Documentation

For a comprehensive guide to evaluating the trustworthiness of the *Excel to Graphviz Relationship Visualizer* workbook - verifying downloads, checking
file hashes, inspecting the macro source, and understanding the SVG postprocessing feature's security model - see the [Security page](https://exceltographviz.com/security/) on the documentation site.
